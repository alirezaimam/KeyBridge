# AI-Assisted Development Disclosure

KeyBridge was created with substantial assistance from generative AI. This
includes application code, build and installer scripts, documentation, tests,
and visual assets.

The project owner directs the work and is responsible for reviewing changes,
testing releases, choosing what to publish, and complying with third-party
licenses. AI-generated material is not a substitute for independent security,
privacy, compatibility, or legal review.

If you contribute to KeyBridge, disclose material use of generative AI in the
pull request description when it helps reviewers understand how the change was
produced or what needs closer verification.
